## Слайд 4. Сервис глазами

Открываем `output/novapay_service.rb`, идём сверху вниз:

- `STATUS_MAP` / `ERROR_MAP` / `RETRY_POLICY` / `EVENT_MAP` — замороженные
  хеши, а не ветки `if`.
- `check_conditions` — сумма меньше 1000 ₽ отклоняется, в комментарии видно
  пересчёт `minimum: 100000` копеек.
- `409` на создании — не ошибка: `DEDUP_STATUS`, ответ читается как успех.
- `process_callback` — подпись → поиск по `payout_id`, потом по
  `external_id` → `EVENT_MAP` на все четыре события → отказ на неизвестном.
- `verify_signature!` — `OpenSSL::HMAC` плюс постоянное по времени сравнение,
  без заголовка — явный отказ.
- `idempotency_key_for` — UUID v5 от `operation.id`, детерминирован.
- `cancel` и `balance` — отдельные публичные методы с пометкой «вне
  контракта» в самом комментарии.
- Секреты — только `provider.credentials[...]`, ни одного литерала.
