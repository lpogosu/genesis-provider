# Принятые допущения

Здесь фиксируется каждое допущение, сделанное там, где кейс или эксперты не
дали формального ответа. Каждая запись дублируется в разделе «Принятые
допущения» сгенерированного `INTEGRATION.md`, чтобы жюри видело границу между
выведенным из спецификации и принятым на веру.

Правила ведения:

- одна строка — одно допущение, без объединения
- источник обязателен: описание кейса, ответ экспертов (с датой) или наше
  решение
- если допущение опровергнуто, строку не удаляем, а помечаем «снято» с
  указанием, чем заменено
